# Listen Loop — YouTube 精听听写

Chrome 插件。在 YouTube 视频页把英文字幕切成一句一句：单句循环听 → 把听到的打出来 → 逐词核对。不依赖任何大模型或外部 API，所有数据只存在本机。

## 安装

1. Chrome 打开 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`listen-loop/`）
4. 打开任意 YouTube 视频，右侧推荐栏顶部会出现 **Listen Loop** 面板

改了代码之后：在 `chrome://extensions` 点插件卡片上的刷新按钮，再刷新 YouTube 页面。

## 怎么用

1. 看视频看到想精听的地方，点 **开始精听**：从当前这句开始，默认循环 3 遍，每遍间隔 1 秒
2. 把听到的打进输入框，按 **Enter** 检查
   - 绿 = 对　橙 = 差一点（如 love / loved）　红 = 错　红虚线 = 漏听　淡红删除线 = 多打
   - 改完再按 Enter 重新检查；不改直接按 Enter 进入下一句
3. 实在听不出来，可以逐级求助：**提示首字母**（`I h___'_ s___ …`）→ **译文**（先看中文意思再听）→ **看原文**
   - 译文用 Chrome 自带的本地翻译（需要 Chrome 138 或更新版本），不花钱，也不会把句子发到外部服务器。第一次使用时 Chrome 会下载翻译模型，面板里会显示进度
   - 翻译前会去掉 uh、um 等语气词；翻过的句子会按视频缓存，下次直接显示
   - 浏览器语言里排在最前的中文是繁体（zh-TW / zh-HK）时翻成繁体，否则翻成简体
4. 自动字幕本身也会错（比如把 Jayson 写成 Jason）。遇到这种情况点「字幕本身可能有误？」标记，这句就算完成
5. 句子切得不准（听到下一句的开头，或者句尾被切掉）：点时间旁边的 **✂ 调整**
   - 开头 / 结尾的 ◂ ▸：每点一下移 0.1 秒，并试听这句的开头或结尾 2 秒
   - **合并下一句**：两句连在一起练；**拆开**：拆回合并前的样子
   - 调整只对当前视频生效，自动保存，下次打开还在

检查时这些写法都算对：大小写、标点；缩写和全拼（hadn't = had not，gonna = going to）；数字和英文（23 = twenty-three）；连写和分写（halftime = half time）。uh / um 等语气词默认忽略。

## 错题本

听不出来、想以后再练的句子，可以加进错题本，按间隔重复安排复习。

- **加入：** 练习时点输入框右下的 ☆，或按 `Alt+B`；检查答案后，结果下方也有「☆ 加入错题本」。只有手动加入的句子才会进错题本。插件会记下这句的时间段、原文，以及你当时写的答案和听错的词。
- **复习时间：** 加入后第 1、3、7、15、30 天各复习一次。
  - 不看任何提示就全对，判「记住了」，进入下一轮；
  - 用了提示才对，或正确率 ≥ 80%，判「模糊」，2 天内再来；
  - 其他情况判「没记住」，从头开始，明天再来；
  - 自动判定的结果可以手动改；
  - 通过第 30 天那一轮，就算「已掌握」。
- **开始复习：** 点面板右上的「错题本」（红点数字是今天待复习的句数），或者点浏览器工具栏上的插件图标，打开错题本页面，再点「开始复习」。复习直接在原视频上进行：自动跳到那一句循环播放，打字、检查、Enter 下一句，下一句在别的视频里时会自动跳过去。中途离开也没关系，回到 YouTube 时面板会提示继续。
- **错题本页面：** 有待复习 / 全部 / 已掌握 / 易错词四个分组。原文默认遮住，点一下才显示。可以单独复习某一句、在原视频中打开、移出错题本；也可以导出、导入备份文件，用来换电脑或防丢。
- 数据只存在本机浏览器里，不需要账号。

## 快捷键

| 按键 | 作用 | 生效范围 |
|---|---|---|
| `Tab` | 重播当前句 | 输入框里 |
| `Enter` | 检查 / 下一句 | 输入框里 |
| `Alt` + `←` / `→` | 上一句 / 下一句 | 页面任意位置 |
| `Alt` + `↑` / `↓` | 加速 / 减速 | 页面任意位置 |
| `Alt` + `R` | 重播（正常看视频时，按一下就回听刚才那句） | 页面任意位置 |
| `Alt` + `H` | 提示首字母 | 页面任意位置 |
| `Alt` + `T` | 显示 / 隐藏译文 | 页面任意位置 |
| `Alt` + `B` | 加入 / 移出错题本 | 页面任意位置 |
| `Alt` + `A` | 看原文 | 页面任意位置 |

在面板里打字时，YouTube 自己的快捷键（空格、K、F、J、L、数字键等）会被屏蔽，不会误触暂停、全屏或跳转。

## 设置（⚙）

**界面语言**：默认跟随浏览器。浏览器界面语言或首选语言是中文（简体、繁体都算）就显示中文，否则显示英文。也可以在设置的「Language / 语言」里手动选「中文」或「English」。扩展名称和描述同样跟随浏览器语言。

每遍间隔、忽略语气词、句子列表是否显示原文、打开视频时自动加载字幕；遮挡画面里烧录的字幕（高度和位置可调）；开关 YouTube 自带字幕；清除本视频记录。设置里还能看到「最常听错的词」，只统计每句的第一次作答。

## 工作原理

- **拿字幕**（`src/page-hook.js`，运行在页面环境）：从播放器读出英文字幕轨，有人工字幕优先用，没有就用自动字幕。YouTube 现在直接请求字幕地址会返回空，所以插件改为读取播放器自己发出的字幕请求；需要的话会自动打开一下 CC 再关掉。
- **切句**（`src/segment.js`）：自动字幕带逐词时间戳，按句号、问号、叹号切句；超过 18 个词或 7 秒的长句，再在逗号或停顿处切开；没有标点的字幕按停顿切。
  - 有些视频的英文自动字幕（网页播放器拿到的是 `variant=gemini` 版本）**没有逐词时间**，只有整行时间。而且每行字幕在屏幕上会停留到下一行之后，显示时长比说话时长长得多。所以一行里的词只按长度摊到下一行开始之前，不按整个显示时长摊。这样估出来的句首时间，中位误差约 0.3 秒；之前按显示时长摊，平均晚了 1 秒多。
  - 不到 4 个词或不到 1 秒、并且和相邻句子连着说的短句（比如 "What's up, everybody?"），会自动并进相邻那句，因为短句的切点误差最明显。
  - 播放时开头和结尾各留一点余量，但和相邻句子之间没有停顿时就不留，免得播到别的句子里去。句首落在一行字幕中间（时间是估出来的）的句子，开头多留 0.2 秒。
- **批改**（`src/check.js`）：两边先统一格式，再按词做最长公共子序列（LCS）对齐。
- **播放**（`src/content.js`）：直接控制页面上的 `<video>` 元素。拖动进度条或手动播放会自动退出循环。

## 已知限制

- 只支持有英文字幕的视频，人工或自动字幕都可以
- YouTube 改版可能让插件失效（页面结构或字幕接口变了）
- 遇到广告时，循环会等广告结束后再继续

## 测试

```bash
node --test test/unit.test.js          # 切句 + 批改，用真实字幕数据
python3 test/e2e.py /tmp/ll-e2e        # 在无头 Chromium 里加载插件做端到端测试
```

YouTube 不给自动化浏览器播放视频、也不给字幕，所以端到端测试跑在 `test/harness.html` 上。这是一个模拟 YouTube 观看页的本地页面，通过 Playwright 路由挂在 `youtube.com/watch` 地址下，不会访问网络。在真实 YouTube 上拿字幕这一步，需要在正常的 Chrome 里手动验证。
